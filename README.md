# Mohamed Hisham Ibrahim — Data Analyst Portfolio

Personal portfolio built with Python and Streamlit.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy (free)

1. Push this folder to a GitHub repo.
2. Go to https://share.streamlit.io, sign in with GitHub, choose the repo.
3. Set the main file to `app.py` and deploy.

## Edit content

All text lives at the top of `app.py` (name, experience, projects, skills).
Add project screenshots in an `assets/` folder and reference them with the `image` key.
